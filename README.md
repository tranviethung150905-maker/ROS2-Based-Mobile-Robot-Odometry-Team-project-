# ROS2-Based-Mobile-Robot-Odometry-Team-project-
ROS2 mobile robot odometry using wheel encoder and optical flow sensor fusion for position and orientation estimation on Raspberry Pi.

## Features

- ROS2 publisher/subscriber architecture
- Wheel encoder and optical flow sensor fusion
- Robot position and orientation estimation
- Real-time odometry visualization using MATLAB

## Technologies

- ROS2
- Python
- Raspberry Pi
- MATLAB

## My Contribution

- Set up initial ROS2 node network using publisher/subscriber communication for robot control and sensor processing.
- Developed control node for robot movement control.
- Implemented sensor fusion combining wheel encoder and optical flow data to estimate the robot's position and orientation.
- Developed a MATLAB-based visualization to display the robot's position and orientation in real time.
